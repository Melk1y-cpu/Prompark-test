# Промышленный парк «Элгрант Пестрецы» — сайт

Одностраничный сайт (HTML + CSS + JS, без фреймворков). Откройте `index.html` в браузере.

- `index.html` — разметка, секции: Hero, О парке, Логистика, Инфраструктура, Участки, Резиденты, Инвесторам, Контакты.
- `css/style.css` — стили, переменные (`:root`), адаптивность.
- `js/main.js` — меню, анимации, счётчики, фильтр участков (данные в массиве `SITES`), форма.
- `js/config.js` — **здесь подключаются** backend формы (`formEndpoint`) и карта (`mapEmbedUrl`).
- `assets/images/` — изображения из презентаций (webp).

## Что нужно уточнить (`[УТОЧНИТЬ]`)
Email, точный адрес и координаты, площадь участков промназначения (11,8 или 13,3 га в разных презентациях),
характеристики воды/водоотведения, статусы участков, названия резидентов, актуальные цены.
